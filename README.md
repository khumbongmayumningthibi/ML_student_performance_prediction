# Student Performance Predictor

A beginner machine learning project that predicts whether a student will pass or fail based on study hours, attendance, and previous marks.

## Technologies
- Python
- Pandas
- Scikit-learn

## ML Concepts
- Supervised Learning
- Binary Classification
- Logistic Regression
- Train/Test Split
- Accuracy Evaluation

## Note
This project uses a small manually created dataset and was built for learning purposes.
